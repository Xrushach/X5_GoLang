# Сервис заказов

Простой сервис заказов, разнесенный по пакетам. При запуске создаётся один заказ с ID 1, клиентом «Покупатель» и статусом `new`, после чего выводится сообщение о том, какой
адрес сервис слушал бы.

## Запуск

go.mod рядом с терминалом

```bash
go run ./cmd/orders
```
## Запуск с другим HTTP
```bash
HTTP_ADDR=:'Порт' go run ./cmd/order
```
