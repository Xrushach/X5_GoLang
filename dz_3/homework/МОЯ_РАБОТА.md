## Что делает программа

Программа рассылает сообщение по двум каналам(email и push). Каждый канал ведет историю отправленных сообщений. При проблеме возвращается ошибка, которую main выводит в консоль

## Как запустить

Команды выполняются из директории dz_3, версия go 1.27

Запуск программы: go run ./cmd/notify
Тесты: go test ./...
Проверка кода: go vet ./...
Проверка форматирования: gofmt -l practice/tasks.go cmd/notify/main.go (при успешном запуске ничего не выводит)

## Проверенные случаи

1. Успешная отправка: оба канала(email и push) приняли "Готов", ошибок не возникло, и в обеих историях появилось сообщение с префиксом своего канала
2. Пустой текст: Dispatch вернул ErrEmptyMessage, при этом истории не изменились
3. Нет настройки: У push не задан DeviceID вернулась ошибка SendError, из которой видно канал push и причину
4. Паника в канале: BrokenNotifier упал, однако SafeDispatch продолжил работу, и следующий push все равно получил сообщение "[push] Заказ готов"

## Обработка ошибок

Dispatch останавливается на первой ошибке, а SafeDispatch обходит все каналы и собирает все ошибки в список
errors.Is служит для проверки конкретной ошибки
errors.As служит чтобы извлечь SendError и прочитать ее поля Channel и Reason
Благодаря тому что recover стоит в SafeSend, то есть охватывает вызов Send, паника не срывает весь циксл, и остальные каналы получают сообщения
